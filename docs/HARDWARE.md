# Железо

## Плата

**Orange Pi Lite** — Allwinner H3 (4×Cortex-A7 @ 1.2 ГГц), 512 МБ DDR3.
Питание — DC 5V (круглый разъём). Включается кнопкой.

40-pin разъём совместим с RPi 3/4 по механическим номерам, **но GPIO H3 на этих пинах — другие** (несовместимо программно!).

## Дисплей

7" HDMI LCD 1024×600 (IN070 + RTD2660A).

- HDMI-кабель к плате
- Режим: 1024×600 @ 60 Гц, pixel clock 51.2 МГц
- HPD сигнал отсутствует — в прошивке force-hotplug
- **USB-тач** — на этих модулях (IN070+RTD2660A) тачскрин реализован через промежуточный
  микроконтроллер, который эмулирует стандартное HID-устройство (мышь/джойстик).
  Чип GT911 используется только на уровне сенсорной панели — к нему нет прямого
  доступа с шины. Плата определяется системой как стандартная HID: видна при
  инициализации USB (VID 0EEF, PID 0005), драйвер GT911 на уровне USB не требуется.
  - В текущей прошивке тач **включён**: `usb_input_poll()` (меню/браузер) читает
    HID-отчёт тача (Report ID 0x01, X/Y 16-бит 0..4095) и зонирует экран
    (верх = Up, низ = Down, середина слева = ESC, справа = Enter), `usb_touch_joy()`
    — тач как джойстик в эмуляторе. Работает через poll HID-устройства, без interrupt-IN.

Дисплей надевается на первые 26 пинов 40-pin разъёма.

## UART (отладка)

- TX: пин 14 (PA4)
- RX: пин 15 (PA5)
- 115200 8N1
- Подключение: USB-UART (FTDI/CP2102), TX→RX, GND→GND

## USB

Два OHCI-порта (USB-A разъёмы):

- **OHCI1** @ 0x01C1B400
- **OHCI2** @ 0x01C1C400

Текущая поддержка:

- **Клавиатура** (Boot Keyboard HID, Logitech 046D:C52B) — работает
- **Тач** (USB HID, VID 0EEF / PID 0005) — работает через poll HID-отчёта:
  `usb_input_poll()` (меню/браузер) зонирует экран (верх=Up, низ=Down,
  середина слева=ESC, справа=Enter), `usb_touch_joy()` — тач как джойстик
  в эмуляторе. Реального драйвера GT911 не требуется: панель с промежуточным
  MCU выглядит как стандартная USB-мышь/HID

## SD-карта (SDMMC0, MMC0)

- Контроллер @ 0x01C0F000
- FIFO на 0x200
- CMD17 (чтение блока 512 байт), поллинг STATUS

## WiFi (RTL8189FTV)

Есть на плате (SDIO, MMC1, порт G). **Не реализован.** Требуется SDIO-стек + загрузка firmware чипа + TCP/IP.

## Светодиоды (индикация)

- **PA15** — красный, «код жив» (мигает в ритме кадров эмулятора)
- **PL10** — зелёный, «обращение к SD» (вспыхивает при чтении сектора)
- Активный уровень **HIGH** (горит при DAT=1)
- PL10 в R_PIO: из bare-metal записи в конфиг не проходят без такта PRCM;
  настраивается штатно через U-Boot `gpio set PL10` в boot.scr (или остаётся в функции 7)

## Геймпад Sega 6-button (PCF8574@0x20, I2C)

Подключение через PCF8574 (I2C, адрес 0x20) на шину **TWI0: PA11=SCL, PA12=SDA** (bit-bang, ~400 кГц). Питание геймпада и PCF8574 — через PL5 (S_PL_EINT5), включает **U-Boot при старте** (прошивка PL5 не трогает).

| Контакт DE-9 | Сигнал | PCF8574 | Направление | Примечание |
|---|---|---|---|---|
| 1 | D0 | P0 | вход | TH=1: **Up**; Цикл4: **Z** |
| 2 | D1 | P1 | вход | TH=1: **Down**; Цикл4: **Y** |
| 3 | D2 | P2 | вход | TH=1: **Left**; Цикл4: **X** |
| 4 | D3 | P3 | вход | TH=1: **Right**; Цикл4: **Mode** |
| 6 | D4 (TL) | P4 | вход | TH=1: **B**; TH=0: **A** |
| 9 | D5 (TR) | P5 | вход | TH=1: **C**; TH=0: **Start** |
| 7 | TH (SELECT) | P7 | выход | запись 0/1 переключает фазу |
| 5 | +5V (VCC) | — | питание | 3.3V через подтяжку 10к |
| 8 | GND | GND | земля | |

Логика кнопок — **активный низ** (зажата → 0). Классический протокол Sega 6-button (проверен на железе, UART `SEGA: r=TH1/TH0/ЦИКЛ4`):

```
ЦИКЛ1 TH=1: P0=Up P1=Down P2=Left P3=Right  P4=B(TL)  P5=C(TR)
ЦИКЛ1 TH=0: P4=A(TL)  P5=Start(TR)          (D2/D3=0 — маркер «геймпад подключён»)
ЦИКЛ2 TH=1→TH=0  (холостой — счётчик чипа)
ЦИКЛ3 TH=1→TH=0  (холостой — счётчик чипа)
ЦИКЛ4 TH=1: P0=Z P1=Y P2=X P3=Mode          (B/C на P4/P5 повторно)
сброс: TH=0 → TH=1 (idle)
```

Драйвер: `h3_bare/cores/sega_pad.c` — `sega_pad_scan()` (bit-bang I2C, 8-шаговый протокол, паузы 3 мкс после SELECT до чтения, весь цикл ~1.27 мс < 1.5 мс лимита). Статус: `sega_pad_init()` + вывод `sega_pad: PCF8574 OK` в boot-лог; `sega_pad_get_status()` (ACK / маркер геймпада).

Маска пада: `Up=0x01 Down=0x02 Left=0x04 Right=0x08 A=0x10 B=0x20 C=0x40 Start=0x80 X=0x100 Y=0x200 Z=0x400 Mode=0x800`.

Тест: **Settings → 5 (Sega 6-button gamepad)** — сырые чтения по фазам и биты на экран, в UART строка `SEGA: r=.. ack=.. pad=.. t=..us` при каждой смене кнопок. Встроен в меню и все эмуляторы (Atari Portfolio — клавиатурный компьютер, геймпад не подключается).

## Память (карта адресов)

| Адрес | Назначение |
|-------|------------|
| 0x40000000 | Код (загрузка U-Boot `go`) |
| 0x50000000 | Буфер загрузки ROM с SD (до 24 МБ) |
| 0x5F800000 | Emu framebuffer 320×240 RGB565 (общий для всех эмуляторов) |
| 0x5F900000 | HDMI framebuffer 1024×600 XRGB8888 |
| 0x60000000 | Стек (конец 512 МБ DRAM, растёт вниз) |

## Дисплейные тайминги

- 1024×600 @ 60 Гц, pixel clock 51.2 МГц
- H: active 1024, hfp 40, hbp 248, hsync 32
- V: active 600, vfp 1, vbp 31, vsync 3
- Флаги: HSYNC_LOW | VSYNC_HIGH
