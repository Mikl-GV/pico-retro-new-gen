# Железо

## Плата

**Orange Pi Lite** — Allwinner H3 (4×Cortex-A7 @ 1.2 ГГц), 512 МБ DDR3.
Питание — DC 5V (круглый разъём). Включается кнопкой.

40-pin разъём совместим с RPi 3/4 по механическим номерам, **но GPIO H3 на этих пинах — другие** (несовместимо программно!).

## Дисплей

7" HDMI LCD 1024×600 (IN070 + RTD2660A).

- HDMI-кабель к плате
- Режим: 1024×600 @ 60 Гц, pixel clock 51.2 МГц
- HPD сигнал отсутствует — в прошивке force-hotplug
- **USB-тач** — на этих модулях (IN070+RTD2660A) тачскрин реализован через промежуточный
  микроконтроллер, который эмулирует стандартное HID-устройство (мышь/джойстик).
  Чип GT911 используется только на уровне сенсорной панели — к нему нет прямого
  доступа с шины. Плата определяется системой как стандартная HID: видна при
  инициализации USB (VID 0EEF, PID 0005), драйвер GT911 на уровне USB не требуется.
  - В текущей прошивке тач **включён**: `usb_input_poll()` (меню/браузер) читает
    HID-отчёт тача (Report ID 0x01, X/Y 16-бит 0..4095) и зонирует экран
    (верх = Up, низ = Down, середина слева = ESC, справа = Enter), `usb_touch_joy()`
    — тач как джойстик в эмуляторе. Работает через poll HID-устройства, без interrupt-IN.

Дисплей надевается на первые 26 пинов 40-pin разъёма.

## SPI-TFT 480×320 (ILI9486, DFR0428) + тач TSC2046I — вторичное ядро CPU1

Дополнительный TFT-экран обслуживает **CPU1** (не нагружает core0):

- **Дисплей** — ILI9486 через 74HC4094×2 + 74HC4040 → параллельная шина D0–D15.
  SPI0 H3: PC0=MOSI, PC1=MISO, PC2=SCLK, **PC3=CS дисплея**, PC7=DC, PA2=RST.
  16 тактов SPI под одним CS (первый байт → D8–D15, второй → D0–D7), подъём CS — лэтч.
- **Тач** — **TSC2046I** (аналог XPT2046/ADS7846), **CS=PA21** (SPI_CE1, пин 26 OPI Lite).
  - Протокол XPT2046: команда **0x90=X, 0xD0=Y, 0xB0=Z1** (давление), 12 бит, данные `value<<4`.
  - **Только SPI Mode 1** (CPHA=1, SDM=1) — в Mode 0 DOUT держит ноль (TCR переключается на время тача и возвращается).
  - Холостой уровень без касания — **~2048 (середина шкалы), НЕ 0**.
  - Нажатие по Z1: `rz4 < 2140` = нет касания.
  - Дефолт-границы: xmin=2350, xmax=3950, ymin=2450, ymax=3700 (калибровка 5 мишеней 1-2-3-4-C пересчитывает).
  - **PA_DAT делится между падом (PA11/12), тачем (PA21) и SD-LED (PA15)** на двух ядрах —
    RMW-гонка смягчена кэшем скана пада 12 мс, sticky-logic и re-init пада на переходах (r155).
- Межъядерная связь — **SRAM A1** (0x34–0x8C: калибровка, кнопки Settings/About, справка,
  F1/F2, меню настроек), не `.coherent` (не работает без инициализации USB).
- Полный TFT-рендер ~1.5+ с (по байтовый SPI 8 МГц) — симптомы «замер экрана» на этой фазе,
  а stall-детектор CPU1 печатает `TFT: slow after …`.
- Стек CPU1: 0x5FE01000; стеки исключений 0x5FDFD000..0x5FE00000 (не пересекаются с FB/кэшем).

## UART (отладка)

- 115200 8N1
- Подключение: USB-UART (FTDI/CP2102), TX→RX, GND→GND

## USB

Два OHCI-порта (USB-A разъёмы):

- **OHCI1** @ 0x01C1B400
- **OHCI2** @ 0x01C1C400

Текущая поддержка:

- **Клавиатура** (Boot Keyboard HID, Logitech 046D:C52B) — работает
- **Тач** (USB HID, VID 0EEF / PID 0005) — работает через poll HID-отчёта:
  `usb_input_poll()` (меню/браузер) зонирует экран (верх=Up, низ=Down,
  середина слева=ESC, справа=Enter), `usb_touch_joy()` — тач как джойстик
  в эмуляторе. Реального драйвера GT911 не требуется: панель с промежуточным
  MCU выглядит как стандартная USB-мышь/HID

## SD-карта (SDMMC0, MMC0)

- Контроллер @ 0x01C0F000
- FIFO на 0x200
- CMD17 (чтение блока 512 байт), поллинг STATUS

## WiFi (RTL8189FTV)

Есть на плате (SDIO, MMC1, порт G). **Не реализован.** Требуется SDIO-стек + загрузка firmware чипа + TCP/IP.

## Светодиоды (индикация)

- **PL10** — зелёный, **«проц жив»**: мигает 0.5/0.5 с с **CPU1** (`led_heartbeat_cpu1`,
  tft_core_main). Вынесен на R_PIO специально (r155) — CPU1 не трогает PA_DAT,
  что сокращает RMW-гонку с Sega-геймпадом (PA11/PA12) и тачем (PA21).
- **PA15** — красный, **«обращение к SD»** (вспыхивает при чтении сектора, `led_sd_on/off`).
  Живёт на PA_DAT (порт A) — при SD-чтении возможны редкие RMW-гонки с падом/тачем.
- Активный уровень **HIGH** (горит при DAT=1)
- PL10 в R_PIO: из bare-metal записи в конфиг не проходят без такта PRCM;
  настраивается штатно через U-Boot `gpio set PL10` в boot.scr (или остаётся в функции 7)

## Звук: MAX98357A (I2S) 

Усилитель I2S (PCM) класса D на **I2S0** (контроллер H3 — master, сам генерит BCLK и LRCK). MAX98357A — slave, данных MCLK не требует (генерятся внутри чипа).

### Подключение (пины 40-pin разъёма Orange Pi Lite)

| MAX98357A | Роль | Orange Pi Lite (I2S0) |
|---|---|---|
| **VIN** | Питание 2.5–5.5 В | **+5V** (или +3.3V, общая точка с H3) |
| **GND** | Земля | **GND** (обязательно общая) |
| **BCLK** | Бит-клок | **PA19 = PCM0_CLK** |
| **LRC** (LRCLK) | Клок L/R каналов | **PA18 = PCM0_SYNC** |
| **DIN** | Данные I2S | **PA20 = PCM0_DOUT** |
| **SD** (на модулях иногда «CD») | Выкл. звука, активный **низкий** | **PG7** — прошивка поднимает в **1** (HIGH = работа) |
| **GAIN** | Усиление | **не подключать** (float) = **9 дБ** (см. таблицу) |

**PA21 (PCM0_DIN)** — не используется: это I2S-вход (микрофон), MAX98357A входа не имеет.

> `SD` на готовых модулях часто уже подтянут резистором к VDD (пин подписан «SD» и работает сразу). Здесь мы управляем им явно через **PG7** (output, HIGH) — это позволяет программно замьютить звук (громкость 0).

### GAIN — усиление (даташит MAX98357A)

| Подключение GAIN | Усиление |
|---|---|
| **не подключен (float)** | **9 дБ** ← основной вариант |
| 100 кОм → GND | 15 дБ |
| GND напрямую | 12 дБ |
| VDD напрямую | 6 дБ |
| 100 кОм → VDD | 3 дБ |

### Обвязка драйвера (bare-metal)

- Контроллер: **I2S0 @ 0x01C22000** (sun8i-i2s, H3-вариант), IRQ SPI 13
- Такт: CCU `BUS_CLK_GATING2` (0x068) бит 12 (I2S0), модульный клок `I2SPCM0_CLK` (0x0B0) бит 31 + mux биты [17:16] (источник pll-audio-8x)
- PIO: **PA18/PA19/PA20** → функция 2 (PCM0_SYNC/CLK/DOUT); **PG7** → output=1 (SD amplifier)
- Формат: I2S 16-bit стерео 44100 Гц, BCLK=32×44100=1.4112 МГц, MCLK=256×44100=11.2896 МГц (mclk_en)
- Регистры (sun8i): CTRL 0x00 (BCLK_OUT/LRCK_OUT=1, MODE=LEFT, TX_EN, GL_EN), FMT0 0x04 (SR=0 16bit, WSS=1, LRCK_PERIOD=31, LRCLK_POL=START_LOW), CLK_DIV 0x24 (MCLK_EN бит8, mclk_div, bclk_div), CHAN_CFG 0x30, TX_CHAN_SEL 0x34 (offset=1 для I2S, CHAN_EN), TX_CHAN_MAP 0x44=0x76543210, FIFO_TX 0x20 (32-bit: L<<16 | R)
- Воспроизведение: поллинг `FIFO_STA` (0x18), запись 16-бит стерео в FIFO_TX
- Микшер: `audio_out.c` — общий буфер всех эмуляторов, **громкость 0..100% (старт 20%)**, настройка в **Settings**, мьют = SD в 0 + FIFO не пишется

### Громкость (Settings → Audio)

- Стартовое значение: **20%** (прошивка). Регулировка в меню Settings (←/→).
- При 0% усилитель отключается через **PG7=0** (SD) — полный мьют без шума.

## Геймпад Sega 6-button (PCF8574@0x20, I2C)

Подключение через PCF8574 (I2C, адрес 0x20) на шину **TWI0: PA11=SCL, PA12=SDA** (bit-bang, ~400 кГц). Питание геймпада и PCF8574 — через PL5 (S_PL_EINT5), включает **U-Boot при старте** (прошивка PL5 не трогает).

| Контакт DE-9 | Сигнал | PCF8574 | Направление | Примечание |
|---|---|---|---|---|
| 1 | D0 | P0 | вход | TH=1: **Up**; Цикл4: **Z** |
| 2 | D1 | P1 | вход | TH=1: **Down**; Цикл4: **Y** |
| 3 | D2 | P2 | вход | TH=1: **Left**; Цикл4: **X** |
| 4 | D3 | P3 | вход | TH=1: **Right**; Цикл4: **Mode** |
| 6 | D4 (TL) | P4 | вход | TH=1: **B**; TH=0: **A** |
| 9 | D5 (TR) | P5 | вход | TH=1: **C**; TH=0: **Start** |
| 7 | TH (SELECT) | P7 | выход | запись 0/1 переключает фазу |
| 5 | +5V (VCC) | — | питание | 3.3V через подтяжку 10к |
| 8 | GND | GND | земля | |

Логика кнопок — **активный низ** (зажата → 0). Классический протокол Sega 6-button (проверен на железе, UART `SEGA: r=TH1/TH0/ЦИКЛ4`):

```
ЦИКЛ1 TH=1: P0=Up P1=Down P2=Left P3=Right  P4=B(TL)  P5=C(TR)
ЦИКЛ1 TH=0: P4=A(TL)  P5=Start(TR)          (D2/D3=0 — маркер «геймпад подключён»)
ЦИКЛ2 TH=1→TH=0  (холостой — счётчик чипа)
ЦИКЛ3 TH=1→TH=0  (холостой — счётчик чипа)
ЦИКЛ4 TH=1: P0=Z P1=Y P2=X P3=Mode          (B/C на P4/P5 повторно)
сброс: TH=0 → TH=1 (idle)
```

Драйвер: `h3_bare/cores/sega_pad.c` — `sega_pad_scan()` (bit-bang I2C, 8-шаговый протокол,
**SCL ~370 кГц** (t_half=130 тиков @97 МГц), паузы фаз **20 мкс** через 64-битную
`h3_hs_timer_lo_us()`, весь скан **~1.4 мс** < окна чипа 1.6 мс). После скана TH возвращается
в **HIGH (idle)**. Статус: `sega_pad_init()` + вывод `sega_pad: PCF8574 OK` в boot-лог;
`sega_pad_get_status()` (ACK / маркер геймпада / 6-btn).

**Про стабильность (r155):** пад переинициализируется (`sega_pad_init()`, запись 0xFF)
при входе в эмулятор и после выхода — лечит «мёртвый» пад после сбоя I2C (гонка PA_DAT
с TFT-ядром при полном рендере). Кэш скана слоя меню 12 мс + паузы циклов меню 16 мс —
частота опросов ~60/с, окно RMW-гонки уменьшено порядком. Удержание выхода
(ESC / Start+Mode) — «sticky»: не рвётся пустыми пакетами клавиатуры.

Маска пада: `Up=0x01 Down=0x02 Left=0x04 Right=0x08 A=0x10 B=0x20 C=0x40 Start=0x80 X=0x100 Y=0x200 Z=0x400 Mode=0x800`.

Тест: **Settings → 5 (Sega 6-button gamepad)** — сырые чтения по фазам и биты на экран, в UART строка `SEGA: r=.. ack=.. pad=.. t=..us` при каждой смене кнопок. Встроен в меню и все эмуляторы (Atari Portfolio — клавиатурный компьютер, геймпад не подключается).
