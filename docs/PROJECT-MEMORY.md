# PROJECT-MEMORY — накопленные знания по проекту (сохранено 2026-10-01)

> Хранилище контекста между чатами. Дополнять при появлении новых важных фактов.
> Обязательные правила — в `AGENTS.md`; точка сохранения — `docs/HANDOVER.md`;
> реестр дефектов/дельт — `docs/CODE-REVIEW-2026-10-01.md`.
> СЕКРЕТЫ (пароли и т.п.) здесь НЕ хранятся намеренно — см. §3.

## 1. Что это

- Проект: **pico-retro-new-gen**, ветка `main`,
  репозиторий `github.com/Mikl-GV/pico-retro-new-gen`.
- Bare-metal мультисистемный эмулятор для **Orange Pi Lite (Allwinner H3)**.
- Структура «с нуля»: реестр систем — `h3_bare/cores/systems.h` (~20 систем,
  3 группы: портативные / консоли / компьютеры); меню — `menu.c` (группировка,
  прокрутка); браузер ROM — `rom_browser.c` (читает `/roms/<id>/`).
- Платформенный код (HDMI, UART, SD/FAT, USB-HID) перенесён из V6.12; эмуляторы
  добавляются поверх.
- Сборка: `./build.sh` (без латок). SD-образ — через `mtools` **без sudo**.

## 2. Правила поведения в проекте

- **Git:** коммит/пуш — ТОЛЬКО по явному указанию («пуш», «коммить»). Без
  запроса — только локальная сборка/правки.
- **Меню/навигация:** главный путь — HDMI (клавиатура/джойстик), БЕЗ изменений.
  TFT — только дополнение (тап иконок Settings/About открывает их TFT-версии).
  HDMI-версии экранов НЕ заменять TFT-версиями, а дублировать/дополнять.
- **Никаких самовольных решений по поведению.** Неясно — спросить. Пример:
  «Create ROM folders» в настройках обязана иметь ДВОЙНОЕ подтверждение
  (предупреждение → «Are you SURE?»), как в HDMI-версии `create_folders_flow`.
  Не упрощать без явного разрешения.
- **Версия — на каждое изменение** (r-нумерация), синхронно в коде и доках;
  **документация — на каждое изменение** (см. AGENTS.md «Правила владельца»).

## 3. Сборка/запуск и sudo

- SD-драйвер `sd.c` наследует инициализацию MMC от U-Boot: отключает IDMAC
  (`dmac=0`, `thldc=0`), читает **PIO** через FIFO. НЕ трогает
  `clkcr/gctrl/CCU/GPIO` — всё уже настроено U-Boot.
- `make fel` (заливка через `sunxi-fel`) требует **sudo**.
- **Пароль sudo в репозиторий НЕ записан** (гигиена GitHub + безопасность).
  Держите его вне git; при необходимости — в локальном `.gitignore`-файле.


## 4. История важных дельт (архив — не переделывать)

- **r180** (аудит `docs/AUDIT-2026-09-27.md`): (1) краш Gearcoleco
  `D:41FEC35C` — адрес был в orphan-BSS libstdc++/newlib (locale-фасеты/guard/
  `__sf`/errno), не покрытой стартовым обнулением (`_bend1`=0x41FEB87C);
  исправлено `*(.bss.*)` в `.bss` линкера (`_bend1`→0x41FECD9C,
  heap→0x41FECDA0). (2) `gb_alloc` выравнивает 8 байт (было 4) — для 64-битных
  VFP/LDRD в Gearcoleco/Lynx/A7800. (3) `_write` в `coleco_compat.c` пишет в
  UART0. (4) флаг 0x74 «игра активна» ставится в `run_emulator()` на ВСЕХ путях.
  (5) H1 deemp-OOB исправлен неполностью (deemp=1..3 → индекс до 703 при палитре
  512) — добавлен guard.
- **r0.249**: `startup.S` — `hex32_uart` НЕЛЬЗЯ держать счётчик цикла в `r1`
  (`uart_dbg` его затирает → цикл не кончался, UART заливался '0', симптом «P:»+
  нули). Счётчик — на стеке; `hex8_uart` держит значение в `r4` (иначе младшая
  цифра всегда печаталась '0').
- **r0.252**: ядро BK (`cores/bk/`) — глобальные имена коллизируют с другими
  ядрами под `--allow-multiple-definition` (`input_state_cb`, `environ_cb`,
  `video_cb`, `audio_cb`, `input_poll_cb`, `io_init`, `sound_init`, `tape_write`,
  `joystick_init`, `mouse_read/write`, `disk_write`). Симптом: extern-ссылка из
  `tty-libretro.o` цепляется к ЧУЖОЙ (незаполняемой) ячейке → NULL → `blx 0` →
  prefetch abort (`P:00000000:0E`, BL внутри `tty_poll`). Лечение — имена в
  `cores/bk/bk_rename.sh` (→`bk_*`). **Правило:** при интеграции ядра проверять
  «undefined-символы bk-объектов ∩ определения не-bk объектов = 0».
- **Vectrex (GCE)** — ОТЛОЖЕН с r0.200: на стенде «изображение не собирается,
  пропадают строки». Рендер-математика/ввод сверены с `libretro.c` и корректны,
  буферы защищены; подозрение — tearing без vsync + скольжение 50↔60 Гц и/или
  застой на BIOS-экране из-за ввода. Заморожено до стабилизации тача/джоя.
  Статус в `systems.h` НЕ меняли (остаётся READY); отметка — в `ROADMAP.md` и
  `AUDIT-2026-09-27.md`.
- **r500** (точка сохранения 2026-09-30, коммит d472478): нумерация сборок
  сброшена с r0.4xx на **r500**. Полный аудит (28 дельт): BSS 141→31 МБ
  (+пул FBNeo 96 МБ в `.noinit_fbn` NOLOAD, GPGX `ext` 1.6 МБ), NEON-обнуление
  BSS в `startup.S`, наш код — `-Wall -Wextra` без предупреждений.
  Вентилятор/ths_fan удалён (Д11). Читы ВЫКЛЮЧЕНЫ (`cheats_reset` в
  `emu_prepare`). Правило: коммит/пуш — только по явному указанию.

## 5. NGP/NGPC, A2600, аудио — детали (актуальные)

- **NGP/NGPC (RACE), r502 — чинилось, подтверждено на стенде** (первые уровни
  без зависаний): (1) исполнение Sub-CPU Z80 в `tlcs_execute` (~1 шаг на 2 такта
  TLCS) — без него игры вечно ждут shared-флаги; (2) ISR-бит `0x70C3 |= 0x01`
  при VBlank (shared с Z80-адресом `0x00C3`) — ждут Sonic/MS2; (3) тик звуковых
  чипов каждый кадр (`soundOutput → sound_update/dac_update`, без I2S);
  (4) хвост `mainrom` заполняется 0xFF + вторая половина в верхний слот (2МБ-игры
  типа Sonic). Симптом до фикса: белый экран, PC=0x3F1C9F/0x28EE7D, спин на
  чтении `0x70C3=00`.
- **Детектор машины NGP** в `main.cpp initRom` — ЭТАЛОННЫЙ SNK (байт 0x23,
  fallback 0x20/0x21) — НЕ менять.
- **Период кадра NGP** в `emu.c emu_run_ngp` = 16200 мкс (~61.7 Гц ядра), общий
  60 Гц восстанавливается на выходе (паттерн CPS).
- **Отложено у NGP:** flash-сейвы (`writeSaveGameFile` — заглушка),
  `setFlashSize` (маленькие homebrew уходят в else-ветку cartSize=32;
  кандидат на правку — cartSize=4). Звук NGP **подключён** с r597 (Д-62).
- **A2600 (MCUME):** TV-режим `a2600_tv_pal` (0=NTSC,1=PAL) — в Settings, пункт
  «Atari 2600 TV mode» в КОНЦЕ enum (индексы TFT-меню не сдвигать); применяется
  ТОЛЬКО в слое A2600 (`system_atari_h3.cpp base_opts.tvtype`). Банк: 8К→1 (F8),
  16К→2 (F6), 32К→6 (F4), 16К SuperChip→5 (F6SC) через CRC-таблицу `a26_crc_bank`
  (пока пуста).

## 6. Аудио/I2S — хронология подключения (послойно)

- **r503:** MAX98357A: LRC=PA18, BCLK=PA19, DIN=PA20 (все — **CFG2**, функция 2
  PCM0); SD/мьют — PA10 (**CFG1**, function 1 = output, HIGH = работа).
  ВАЖНО: до r503 `i2s.c` настраивал PA18/19/20 через **CFG3** (это PA24..31) —
  баг исправлен на CFG2. `i2s_init()` вызывается в `main()` при старте; звук
  эмуляторов к I2S ещё не подключён. Тест-тоны: Settings → Audio test
  440/1000/3000 Гц (2 с).
- **r504:** Settings → «Audio volume» (шаг 5 %, 0..100, старт 20 %) через
  `i2s_volume()`; тест-тон снижен до 50 % амплитуды.
- **r505:** `i2s_click()` (5 мс, 1.5 кГц, ~25 %) при Up/Down в `menu.c`/
  `settings.c`; синус-таблица вынесена на уровень файла.
- **r506:** Линкс первым: Handy отдаёт 48 кГц моно int16
  (`gAudioBuffer`/`gAudioBufferPointer` — совпадает с I2S, пересчёт не нужен);
  `lynx_host.cpp` пушит `i2s_push_sample(s,s)`; `emu_throttle` доливает кольцо
  при неготовом I2S — старый `udelay`; `emu_prepare` чистит кольцо
  `i2s_ring_reset()`. Добавлены `i2s_ready()`/`i2s_ring_reset()`. (Примечание:
  с r549 долив идёт порциями `i2s_flush_max(24)` — fire-and-forget, не по
  1 паре.)
- **r507:** Lynx — ДВА обязательных звена: (1) `gAudioEnabled=TRUE` после
  `new CSystem` (по умолчанию FALSE, иначе `Mikie::Update` не обновляет аудио,
  mikie.cpp:3224); (2) `g_lynx->FetchAudioSamples()` после кадра — единственный
  вызов `AudioEndOfFrame()` (system.h:231), иначе `gAudioBufferPointer=0`. Формат:
  `gAudioBuffer` = стерео int16 L,R (blip Stereo_Buffer end_frame, was_stereo=true),
  пары = `gAudioBufferPointer/2`.
- **r508:** DC-blocker (HPF ~30 Гц) + мягкий лимитер в `i2s_push_sample`
  (причина: на Lynx «жирные басы/перегруз/нет верха» — blip даёт DC).
- **r520** (коммит `a5f89dc`, точка восстановления): звук Lynx на I2S полностью
  (темп 75 Гц/48к, DC-срез 240 Гц, FIR-сглаживание, громкость/тест-тоны/щелчки,
  мьют PA10). **Актуально (r577):** FIR/лимитер позже сняты (r551/r558 —
  «FIR/лимитер не возвращаем»), остался только DC-блокер ~240 Гц (DC_SHIFT=5,
  r558/r572) + громкость + кламп. История фильтров: r508 DC+лимитер → r520 добавил
  FIR → r551 всё снято → r558 возвращён только DC → r560 DC 480 Гц → r572 DC 240 Гц.
- **r521:** звук GBA (gpSP) — ресемпл **65536→48000** в `gba_host.c` (линейная
  интерполяция, фаза 16.16, шаг 89478, непрерывна между кадрами) →
  `i2s_push_sample`. I2S остаётся 48 кГц (честных H3-делителей под 65536 нет;
  ровный 48к = PLL/8). gpSP: `sound_frequency=65536` (степени двойки), стерео s16
  интерливed, `sound_read_samples` возвращает пары. **Актуально (r577):** с r524/
  r525 ядро переведено на **32768 Гц** (`sound_frequency=32768, sound_freq_bits=15`,
  gba_host.c:159-165), ресемпл **32768→48000** (шаг `GBA_RS_INC 44739u`,
  ~804 пары/кадр, cap 900).

## 7. Текущее состояние (2026-10-02)

- Версия прошивки: **r615**; `h3_bare.bin` ≈ 13528412 байт (r615).
- **Аудио-ядро CPU2 (Ф0/Ф1, r584/r585):** долив звука I2S обслуживает CPU2
  (audio_core.c: cpu2_audio_entry, вечный цикл 48 кГц), а не core0. core0
  синтезирует и кладёт в кольцо; кольцо/почта/dc — в `.coherent` (uncached);
  cpu2_entry (startup.S: стек 0x5FC01000 + NEON + magic 0x13579BDF);
  emu_throttle при активном CPU2 — только ожидание периода (fallback старый
  путь). UART0 пишет только core0 (CPU2 — числа в .coherent). Подробно:
  docs/HANDOVER.md §5a, docs/ARCHITECTURE.md, Д-49/Д-50.
- Звук на I2S (r615): **15 систем** — Lynx, GBA (полифаз 32768→48000), GB/GBC,
  NGP (44100→48000), MD/SMS/GG, NES, SNES, A2600, A5200, A7800, Coleco, PCE
  (44100→48000), ZX Spectrum (44100→48000), аркады FBNeo. Не подключены:
  MSX, Vectrex, BK-0010, Portfolio, MS1504.
- Реестр дефектов и статусы: `docs/CODE-REVIEW-2026-10-01.md` (журнал дельт
  Д-1..Д-42; F1..F8 статусы), свежий код-ревью — `docs/REVIEW-2026-10-02.md`.
- Серия r562..r577 закоммичена и запушена (bb44815). Следующие — правки доков
  (Д-43..Д-46) и F6/F7/F8 (Д-47/Д-48).
