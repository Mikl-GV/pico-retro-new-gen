# Управление (Controls)

USB-клавиатура (Boot HID) + Sega-геймпад 6-button через PCF8574@0x20 (bit-bang I2C: **PG9=SCL, PG8=SDA**, r614).
Дополнительно: **8-битный кнопочный пад PCF8574@0x27** (r0.395, `cores/btn_pad.c`) — кнопка на каждую линию. (В `btn_pad_probe()` приоритет у 0x27; 0x20 используется только если там нет Sega-джойстика. На стенде владельца кнопки — на 0x27.)

## 8-битный кнопочный пад (r0.395)

| Линия PCF8574 | Кнопка | Маска |
|---|---|---|
| B0 (0x01) | Вверх | UP=0x0001 |
| B1 (0x02) | Влево | LEFT=0x0004 |
| B2 (0x04) | Вправо | RIGHT=0x0008 |
| B3 (0x08) | Вниз | DOWN=0x0002 |
| B4 (0x10) | Кнопка A | A=0x0010 |
| B5 (0x20) | Кнопка B | B=0x0020 |
| B6 (0x40) | Start | START=0x0080 |
| B7 (0x80) | Select / Coin (аркады) | X=0x0100 |

Активный низ (нажатие = 0 на бите), как у Sega-пада.

Подключён **на все эмуляторы и в меню**: host-слои используют
`pad_scan_combined()` = `sega_pad_scan() | btn_pad8_scan()`.

Поведение:
- **Меню**: B = назад (ESC), A = выбор (Enter), направления — навигация,
  удержание D-Pad — автоповтор (перебор пунктов).
- **Эмуляторы**: D-Pad/A/B/Start как игровые кнопки; Select = Coin (аркады).
- **Выход из эмулятора**: удержание **Start ~0.9 с** (как ESC; emu.c hold >900000 мкс).

> ⚠️ `cores/sega_pad.c` (Sega 6-button протокол) — НЕ ТРОГАТЬ: это отдельный,
> хрупкий модуль; 8-битный пад живёт в `cores/btn_pad.c` и не вносит в него изменений.

## Меню (глобальное)

| Действие | Клавиатура | Sega-геймпад |
|----------|------------|--------------|
| Вверх / Вниз | ↑ / ↓ | D-Pad |
| Влево / Вправо | ← / → | D-Pad |
| Открыть систему / запустить ROM | Enter | A / Start |
| Назад (главное меню / подменю) | ESC | B |
| Settings / Help / About | Enter на пункте | A / Start |

> Клавиатура и геймпад **равноправны** (r155): ни один источник не «перебивает»
> другой; одновременные события не теряются.

**A2600 (Stella, r1533/r1537):** **R** = Game Reset (пуск игры), **Enter** = Game
Select, **Q/W** = сложность левого/правого джойстика, **C** = Color/B&W, **E** = Fry
(холодный сброс). Тип контроллера — по MD5 рома: paddle-игры управляются стрелками
(Paddles читает те же JoystickZero*), keypad-игры — верхний ряд 1..0 (порт 0) и
цифровой блок (порт 1), `-`/`=` и numpad `*`/`+` = `*`/`#`. Второй paddle (порт 1)
не кормится — 2-игровые paddle-игры потребуют доработки.

## Hot-swap дискет (F12, r1363)

В компьютерных эмуляторах **F12** открывает смену дискеты без сброса машины:
список образов текущего каталога (откуда запущена игра), фильтр по
расширениям системы. Если приводов несколько — сначала выбор привода.
Навигация — стрелки, Enter — вставить, ESC — отмена. После закрытия оверлея
клавиши дожидаются отпускания и в машину не попадают.

| Система | Приводы | Образы |
|---|---|---|
| Apple II+ | 2 | `.dsk .do .po .nib .woz` |
| Агат-9 | 1 | `.dsk .nib .aim` |
| ZX Spectrum (Fuse) | 1 | `.dsk .trd .scl .ipf .dck`¹ |
| Amstrad CPC | 2 | `.dsk` |
| Commodore 64 | 2 | `.d64 .t64 .x64 .p00 .zip` |
| Amiga (UAE4All) | 1 | `.adf .adz .dms .ipf` |
| Atari 800 | 1 | `.atr .xfd .dcm .atx` |
| MSX (r1369) | 1 | `.dsk .fdi .trd .scl .img` |
| Enterprise (r1369) | 1 | `.img .dsk` |

¹ Только на машинах с активным дисковым интерфейсом (+3, Beta128, Disciple,
PlusD, Opus); на 48K диска нет — вставка сообщит об ошибке.
² MSX: дисковая подсистема (WD1793 + DISK.ROM/MSXDOS2) включена с r1369;
диск монтируется в A: и картридж при этом не грузится.
³ Enterprise: образ монтируется в дисковод A: (WD177x) через файловый слой;
автозапуск START применяется только к EXOS-программам, не к дискам.

## Агат-9 (r1345)

Клавиатура — обычная USB, маппинг снят с файла раскладки эталона
(`app/keyb/default.bin`, раскладка ЛАТ), а не с встроенной таблицы.
Регистр букв, как на Apple II/Агате: **без Shift — заглавные, с Shift —
строчные** (не наоборот). Машина стоит в ЛАТ (`$C063 = $FF`, r1338),
кириллические коды host не отдаёт вовсе — иначе латинский ввод превращался
в русские буквы. ESC-удержание — выход в меню (как во всех ядрах).

Важно: у Агата код клавиши — 7-битный КОИ-7 плюс бит 7 (строб), и разные
клавиши выдают **один и тот же** код. Поэтому `Backspace` и `←` — это `$88`
(на реальной машине ЗБ и стрелка влево неразличимы), `→` = `$95` (= NAK,
как Ctrl+U), `Enter` = `$8D` (CR), `Tab` = `$89` (HT).

| Клавиша | Код Агата | Действие |
|---------|-----------|----------|
| A..Z | $C1..$DA | Заглавные буквы (с Shift — строчные) |
| 1..0, знаки | ASCII | Цифры и знаки; Shift — символы (`!@#$%…`) |
| Enter | $8D | Ввод (ВК) |
| Backspace | $88 | Забой (ЗБ); на Агате это тот же код, что «←» |
| Tab | $89 | Табуляция |
| Пробел | $20 | Пробел |
| ↑ ↓ ← → | $99 $9A $88 $95 | Родные коды Агата (← = $88, совпадает с ЗБ) |
| Home / End | $8B / $9D | Начало строки / конец |
| PgUp / PgDn | $92 / $9F | Страница вверх / вниз |
| Insert / Delete | $81 / $82 | Вставка / удаление |
| F1..F3 | $84..$86 | Функциональные (Агат) |
| Цифровой блок 2/4/6/8/5 | $9E $93 $9C $91 $94 | Отдельный блок Агата (стрелки и центр) |
| Esc | $9B | АР2 |
| Ctrl | — | Модификатор не используется: русские коды не отдаются |

### Джойстик, пад и кнопки (r1344)

Работают одновременно два канала — клавиатура, Sega-пад и 8-битная панель:

| Ввод | Джойстик Агата ($C070/$C064/$C061) | Клавиатура ($C000) |
|---|---|---|
| Крестовина ↑ ↓ ← → | педали X/Y в крайние положения | `$99` `$9A` `$88` `$95` |
| A | кнопка 0 | пробел (`$A0`) |
| B | кнопка 1 | пробел (`$A0`) |
| Start | — | ВК (`$8D`) |
| USB-клавиатура | — | как обычно, см. таблицу выше |

Игры, читающие `$C000`, видят стрелки и пробел; игры с педалями — положения
и кнопки. Удержание даёт автоповтор (0.5 с, затем ~25 Гц).

## Apple II+ / Apple II (POM2, r1388/r1393/r1395)

Ядро — порт **POM2** (`ports/pom2`), не Agat. Клавиатура USB: код уходит в
`$C000` (бит 7 — строб), `$C010` строб снимает; нажатие и отпускание
передаются раздельно (`setKeyHeld`), поэтому работают игры, которые читают
клавишу в цикле и ждут удержания.

| Клавиша | Код/действие |
|---------|--------------|
| A..Z | заглавные (у ][/][+ строчных нет) |
| 1..0 | цифры; Shift — `!@#$%^&*()` |
| Enter / Esc / Backspace / Tab / пробел | `$0D` / `$1B` / `$08` / `$09` / `$20` |
| `- = [ ] \ ; ' , . /` | ASCII; Shift — верхние символы |
| Стрелки | Ctrl-H / Ctrl-J / Ctrl-K / Ctrl-U (`$08/$0A/$0B/$15`) |
| ESC (удержание ~1 с) | выход в меню |
| F12 | смена дискеты (2 привода, r1396) |

Джойстик: пад (Sega 6-button или 8-битный PCF8574) → паддлы 0/1 (2/3 их
повторяют), A/B → кнопки паддла 0/1 (`$C061-$C063`). Дубль с клавиатуры:
стрелки двигают оси (крайние значения 0/255, центр 128), пробел — кнопка 0.
Чтение паддлов — `$C064-$C067` / `$C070`.

## Game & Watch / Электроника (murmulator SM5xx, r1544–r1547)

Ядро — порт **murmulator** (`h3_bare/cores/gw`, чипы SM500/SM5A/SM510/SM511).
Вход — `gw_get_buttons()`: 8 бит ядра (LEFT/UP/RIGHT/DOWN, GAME A, GAME B,
TIME, GAME) плюс две программные комбинации: бит 10 = B+TIME (режим
времени/демонстрации), бит 11 = B+GAME (будильник). Биты pause/power (8/9)
ядро игнорирует, поэтому «сброс» = перезапуск состояния ядра.

| Клавиша | Действие |
|---------|----------|
| Стрелки | D-Pad (LEFT / UP / RIGHT / DOWN) |
| Z | GAME A |
| X | GAME B |
| Enter | GAME (старт игры) |
| T | TIME — часы / режим демонстрации (бит 10) |
| A | ALARM — будильник (бит 11) |
| R | AC-сброс (`gw_system_reset`) |
| ESC (удержание) | выход в меню |

Подменю при входе: **IM-XX → `/roms/gw/RUS`** (Электроника), **G&W →
`/roms/gw/ENG`** (оригинальные). Экран — 320×240, вывод через DE2 GSU ×2.

Геймпад Sega и клавиатура — **равноправные параллельные источники ввода** (r155). Маппинг от «сеговского эталона», у систем мапятся только существующие кнопки. **Правило проекта: пауза/подтверждение — Start, а не Mode (r155).**

- В меню геймпад работает как клавиатура: D-Pad = навигация, **A/Start = Enter**, **B = ESC**. (Mode → S; r0.181: в браузере S = поиск ROM по букве).
- Atari Portfolio — клавиатурный компьютер, геймпад **не подключён**.
- **MSX**: Sega-пад = **джойстик** (D-Pad; A/C/Y/Start → Fire A, B/X/Mode → Fire B), клавиатура — полная (r0.211: `JOYTYPE=JOY_STICK`, оба порта, 50 Гц).
- **ZX Spectrum (Fuse, r0.242)**: клавиатура — полная (`a–z`, `0–9`, Space, Enter, Shift=Caps Shift, Ctrl=Symbol Shift; ядро читает клавиши на порту 2). Пад: D-Pad + A/B/X/Y = Kempston, Start = Enter, Mode = Space. Выход — **удержание ESC ~0.9 с** (детект из того же отчёта, что читает ядро) или Start (удержание). Выбор модели и ROM/BASIC — в меню до запуска.
- **BK-0010/0011М** (r0.259): полная клавиатура (USB; `a–z`, `0–9`, Space, Enter, Shift, Ctrl — ядро читает по `RETROK_*`), Sega-пад как джойстик (D-Pad; A=кнопка 1, B=2, X=3, Y=4, Start, Mode). Спецклавиши БК: Esc=Стоп, Enter=ВК/ВВОД, Backspace=ЗБ. Выбор модели (6 шт.) затем ROM (`.bin/.img` из `/roms/bk0010/`) или **BASIC** — в меню до запуска. Модель «BK-0010» грузит FOCAL, BASIC — у «BK-0010.01»; FOCAL/монитор — ч/б (r0.253: цвет выключен по умолчанию).
- Меню читов убрано (r0.181) — чит-функция больше не открывается из браузера.

## Джойстик: внутреннее устройство (читать перед разработкой)

> **⚠️ НЕ ЛАЗИТЬ без стенда.** `h3_bare/cores/sega_pad.c` — самый хрупкий файл
> проекта: тайминги и фазы I2C подобраны эмпирически и проверялись итерациями
> r147–r157. Любая правка обязана пройти Settings → Sega 6-button test.

### Как это работает
- Железо: Sega 6-button → PCF8574@0x20 (I2C), bit-bang на **PG9=SCL / PG8=SDA** (r614; до r614 был PA11/PA12).
- Скан: **8 уровней TH** по классическому протоколу; старшие кнопки (X/Y/Z/Mode) —
  в ур.7, только после маркера 6-btn (ур.6); весь скан ~1.4 мс (окно чипа 1.6 мс);
  после скана TH=HIGH (idle).
- **Clash-защита (r157)**: линии D0–D3 общие для крестовины (ур.1) и X/Y/Z/Mode (ур.7),
  поэтому старшая кнопка выдаётся лишь если её линия не занята крестовиной. Иначе
  «вправо» давало фантомный Mode (→ Select), «влево» → X и т.д.
- Маска: UP=0x01 DOWN=0x02 LEFT=0x04 RIGHT=0x08 A=0x10 B=0x20 C=0x40 START=0x80
  X=0x100 Y=0x200 Z=0x400 MODE=0x800.

### Два пути использования (не путать)
| Путь | Кто | Опрос | Кэш/дребезг |
|------|-----|-------|-------------|
| Меню/браузер/настройки | `usb_input_poll` → `usb_pad_update` (usb_kbd.c) | ≤1 скан / 12 мс | кэш 12 мс + 3 одинаковых скана + автоповтор |
| Игры (host-слои) | `pad_scan_combined()` в `build_input` | 1 скан / кадр | мимо кэша (нормально) |

### Защиты от «доезда» и сбоев
- `sega_pad_init()` (запись 0xFF, TH=1) — на входе и выходе эмулятора.
- Выход из игры: **Start ~1 с** (r0.389) (emu.c: armed + sticky — не рвётся пустыми
  пакетами клавиатуры и не срабатывает от «доехавшей» кнопки).
- Меню-циклы имеют паузу 16 мс — чтобы не дёргать I2C каждые 2 мс.

### Почему «не лазить»
- PA_DAT (0x01C20810) делят CPU0 (PA10 SD-усилитель, PA15 SD-LED) и CPU1 (PA21 тач, PA2 RST TFT только в tft_init) —
  битовые `|=` / `&=` не атомарны, RMW-гонка срывает I2C. Мигалка «alive» уведена на PL10. Sega-пад с r614 на порту G (PG9/PG8) и PA_DAT не пишет.
- Любое изменение таймингов (`t_half=130`, паузы 20 мкс), порядка фаз или clash-защиты
  ломает детект 6-btn — симптомы: кнопки «плывут», крестовина жмёт Select/Reset.

## Atari Portfolio (полная клавиатура)

Portfolio — полноценный компьютер DIP DOS, **игровой маппинг отсутствует**.  
Управление — как на настоящей клавиатуре:

| Клавиша | Действие в Portfolio |
|---------|---------------------|
| A-Z, 0-9 | Ввод текста |
| Shift + буква | Заглавные / символы |
| Enter | Enter / выполнение команды |
| Backspace | Удалить символ слева |
| Стрелки | Курсор (в DOS) / навигация по VK |
| Insert | Открыть/закрыть экранную клавиатуру (VK) |
| ESC (удержание ~1 сек) | Выход в меню |
| F1-F12 | Не используются |

Команды DIP DOS:
- `PIN` + Enter — анимация «взлома» (Terminator 2 style)
- `APPS` + Enter — меню встроенных приложений (калькулятор, редактор, таблицы, контакты, дневник)
- `HELP` + Enter — справка по DIP DOS
- `EXIT` + Enter — выход в меню (альтернатива удержанию ESC)

### Экранная клавиатура (VK)

Insert → открыть VK. Стрелки + Enter → выбор символа.  
Esc → закрыть VK. Shift/Caps → переключение регистра.
## Commodore Amiga (PUAE)

Управление — USB-клавиатура (полный HID→RETROK сканкод-маппинг: буквы, цифры,
F1–F12, стрелки, Enter, Backspace, Tab, Esc и т.д.) + Sega-геймпад как джойстик:

| Кнопка Sega | Джойстик Amiga |
|-------------|----------------|
| Крестовина   | D-Pad (вверх/вниз/влево/вправо) |
| A           | Fire 1 (левый) |
| B           | Fire 2 (правый) |
| Start       | не используется (в игру — через Enter на клавиатуре) |

ESC (удержание ~1 сек) — выход в меню. Kickstart не требуется: работает встроенный
AROS-фолбэк (вшит в прошивку); при наличии .adf в /roms/amiga грузится дискета.
