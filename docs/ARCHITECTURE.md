# Архитектура

V5 — bare-metal мультисистемный эмулятор для Allwinner H3. Без ОС,
без фреймворков. Каждый компонент написан с нуля (кроме HDMI-стека,
который взят из lib-h3 с MIT-лицензией).

## Слои

## cpu6502 — ядро 6502

Switch-диспетчер (не computed goto — на ARM switch компактнее).
Память — через `read(ctx, addr)` / `write(ctx, addr, val)` колбеки.

Поддерживаются:
- Все 151 официальный опкод
- BCD (ADC/SBC в десятичном режиме)
- Страничные штрафы для ABSX/ABSY/INDY (дополнительный цикл)
- Ветвления с учётом страницы
- JMP (indirect) с bug-замыканием страницы (оригинальный 6502)

## a2600 — Atari 2600 (TIA + RIOT)

**Рендер:** перехват записей в TIA за строку (76 циклов CPU → 228
цвет-тактов). 192 видимые строки.

- Playfield (20 бит, зеркало/повтор/score/priority)
- 2 игрока (GRP0/GRP1, NUSIZ, REFP)
- 2 мясла, балл
- WSYNC (останов CPU до конца строки)
- HMOVE/HMCLR
- Палитра NTSC (8 оттенков × 16 яркостей)

ROM 4K/8K/F8/F6/FE банкинг — в зачаточном состоянии (прямой доступ).
Для теста вшит kernel: меняет цвет фона каждый кадр.

## a5200 — Atari 5200 (ANTIC + GTIA + POKEY)

**Рендер:** обход display list из RAM. ANTIC-режимы 0–F (char и bitmap).

- Display list: LMS, JVB, DLI, H/V scroll (заглушки)
- Bitmap: 160×1/2bpp, 320×1bpp
- Текст: 40 колонок, charset из CHBASE
- GTIA: COLBK, COLPF0–3, HPOS/SIZEP/GRAFP для PMG
- Player/Missile graphics (упрощённо)

**BIOS:** 5200 без BIOS не стартует (векторы сброса в BIOS @ $F800).
В прошивке встроен мини-BIOS (2K: SEI → JMP $4000 + векторы).

## a7800 — Atari 7800 (MARIA + TIA + RIOT)

**Рендер:** обход DLL (Display List List) → Display List → построчный рендер.

- DLL: 3-байтные записи [flags+offset, DL_hi, DL_lo]
- DL: 4-байтные [addr_lo, pal+width, addr_hi, hpos]
- 8 палитр × 4 цвета (регистры $21, $25, $29, $2D, $31, $35, $39, $3D)
- 320-режимы (1bpp), 160-режимы (2bpp с дублированием)
- Kangaroo-режим (цвет 0 = непрозрачный)
- Extended-записи (indirect) пока пропускаются

Векторы сброса — в картридже (последние 16K отображаются в $C000–$FFFF).
Asteroids (16K) вшит напрямую.

## HDMI (DE2 + DW-HDMI, MIT lib-h3)

Инициализация из `lib-h3` (MIT, автор Arjan van Vught):

1. PLL_DE → 432 МГц, PLL_VIDEO → 297 МГц
2. DE2 mixer0 → UI канал → framebuffer XRGB8888
3. TCON1 → LCD0 → HDMI PHY/DW-HDMI
4. Force-hotplug: если HPD нет — не фатально, инициализация продолжается
   (нужно для 7″ панелей, которые не дают HPD)

Физический режим: **1024×600 @ 60 Гц** (51.2 МПикс/с).
Масштаб до эмуляторных 320×240: nearest-neighbour 3× (каждый пиксель
эмуляции → 3×3 блок в HDMI-буфере).

## Сенсор (XPT2046)

Bit-bang SPI на PC0/PC1/PC2, CS на PA21, IRQ на PA2.
- Команда 0x90 = измерение X+ (12 бит)
- Команда 0xD0 = измерение Y+ (12 бит)
- IRQ низкий = касание обнаружено
- Калибровка: `touch_set_cal(xoff, yoff, xscale, yscale)`

## Загрузка

Через U-Boot:
1. SPL инициализирует DRAM
2. U-Boot загружает `h3_bare.bin` из FAT в 0x42000000
3. `go 0x42000000` → startup.S → SVC mode → BSS=0 → main()

Или через FEL (USB): `sunxi-fel write 0x40000000 h3_bare.bin execute 0x40000000`

## Производительность

Все три ядра на H3 (4× Cortex-A7 @ 1.2 ГГц) идут с большим запасом.
CPU-эмуляция (~30K циклов/кадр) занимает < 0.5 мс. Рендер кадра
(320×240 RGB565 → 1024×600 XRGB8888) — ~200 мкс основной, ~800 мкс
блит. В сумме < 2 мс на кадр из 16.6 мс (60 FPS).
