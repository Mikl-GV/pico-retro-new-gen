# Масштабирование изображения (CPU Nearest Neighbour, по высоте)

## Решение

Аппаратный скейлер DE2 (VI+VSU или UI+GSU1) на H3 в bare-metal **не завёлся** —
регистры не отвечали, гарантированного пути в обход ядра Linux нет.
Поэтому используется **CPU nearest neighbour с растяжкой на всю высоту**:

- Один общий буфер `EMU_FB` (0x5F800000, 320×240 RGB565 = 150 КБ)
- Каждый эмулятор пишет кадр в левый верхний угол `EMU_FB` в родном разрешении
- `emu_scale()` растягивает кадр на **всю высоту экрана (600)**, ширина — пропорционально
- По бокам остаются чёрные поля (соотношение сторон сохраняется)
- Чёткие пиксели, без размытия, ~1-2 мс на кадр на Cortex-A7

## Выходные размеры (высота = 600 всегда)

| Система | Родной размер | Ширина на экране | Боковые поля |
|---------|:-------------:|:----------------:|:------------:|
| **NES** | 256×240 | 640 (×2.5) | 192+192 |
| **A2600** (MCUME) | 160×192 | 500 | 262+262 |
| **A5200** | 320×240 | 800 | 112+112 |
| **A7800** | 320×240 | 800 | 112+112 |
| **SMS** | 256×192 | 800 | 112+112 |
| **Game Boy** | 160×144 | ~667 | ~179+179 |
| **Lynx** | 160×102 | ~941 | ~42+42 |
| **SNES** | 256×224 / 256×240 | ~685 / 640 | ~170+170 / 192+192 |
| **Mega Drive** | 320×224 / 256×224 | ~857 / ~685 | ~84+84 / ~170+170 |
| **Vectrex** | 330×410 (векторный) | ~483 | ~270+270 |

## API

```c
// emu.h
void emu_scale(int src_w, int src_h);
```

- `src_w/src_h` — родное разрешение (кадр в левом верхнем углу EMU_FB)
- Высота вывода всегда 600, ширина = src_w * 600 / src_h
- Картинка центрируется по горизонтали

Вызов: сразу после прорисовки кадра, перед `fb_flush()`.

## Реализация

```c
void emu_scale(int src_w, int src_h) {
    int dst_w = (src_w * FB_H) / src_h;   // 600 = вся высота
    int dst_h = FB_H;
    int dst_x = (FB_W - dst_w) / 2;       // центр по горизонтали

    for (int dy = 0; dy < dst_h; dy++) {
        int sy = (dy * src_h) / dst_h;    // nearest: строка источника
        for (int dx = 0; dx < dst_w; dx++) {
            int sx = (dx * src_w) / dst_w;
            dst[dy * FB_W + dst_x + dx] = RGB(EMU_FB[sy * EMU_W + sx]);
        }
    }
}
```

Это чистый nearest neighbour: каждый пиксель вывода берёт ближайший пиксель
источника (масштаб не целый, поэтому без размытия, но с лёгкой «лесенкой»
на диагоналях — ожидаемо для ретро).

## Память

| Адрес | Размер | Буфер |
|-------|-------:|-------|
| 0x5F800000 | 150 КБ | EMU_FB (320×240×2, один на всех) |
| 0x5F900000 | 2.4 МБ | HDMI FB (1024×600×4) |
| 0x50000000 | 24 МБ | ROM-буфер |

Распределение статичное, без heap, без утечек. Каждый host-слой сбрасывает
свой bump-аллокатор в `*_init_game`.

## История (почему так)

1. **VI+VSU** — чёрный экран (ROUTE=0 ломал трубу)
2. **UI+GSU1** — «градиент» без скейлинга, регистры GSU не читались
3. **CPU Integer Scale (×2/×3)** — работал, но не использовал полную высоту
4. **CPU Scale по высоте (текущий)** — ✅ вся высота, поля по бокам

Эксперименты (h3_de2_scaler.c/.h) удалены из кода и из этого документа.
