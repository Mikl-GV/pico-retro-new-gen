## 1. Что это

Bare-metal мультисистемный эмулятор для Orange Pi Lite (Allwinner H3, Cortex-A7,
512 МБ, без ОС). Один бинарник `h3_bare.bin` грузится U-Boot/FEL по адресу
0x40000000. HDMI 1024×600 (меню/игры, core0) + SPI TFT 480×320 (справка/тач,
CPU1 — дополнение, не основной путь). ROM — SD/USB (FAT32), ввод — USB-клавиатура
(OHCI) + Sega-геймпад/кнопочный пад (PCF8574, bit-bang I2C на PG9/PG8).
27 систем READY (`h3_bare/cores/systems.h` — источник истины).

**Звук:** вывод снят с r777 (`i2s.c` — no-op, CPU2 — `wfi`); синтез в ядрах и
host-слоях сохранён. Возврат — отдельная дельта (`docs/ROADMAP.md`).

## 2. Сборка и проверка

```bash
make clean && make -j$(nproc)     # build/h3_bare.bin + копия в корень
```

- Тулчейн: `arm-none-eabi-gcc` 15.2.1 в PATH (иначе Makefile молча уйдёт на
  `arm-linux-gnueabihf-`).
- После правки любого `.h` — **обязателен** `make clean` (зависимостей нет).
- Windows/MSYS2: `bash -lc 'export PATH=/c/ARM/gcc-arm-none-eabi-15.2.1/bin:$PATH; cd /e/Giga_1/pico-retro-new-gen && make clean && make -j8'`.
- Версия: `g_fw_version` и `build:` в `h3_bare/src/main.c`; инкремент на каждую
  принятую дельту. Текущая — **r856**.
- Стенд — у владельца; в чате доступна только сборка/статика.

## 4. Что осталось / отложено

- **Пароли Wi-Fi** зашиты в `wifi_layer.c` (`8645449Qq`, `B236f8g4`) — решение
  владельца: не на этом этапе. Вынести в `/retro.cfg` — отдельная дельта.
- **USB/GBA (r856)** — MSD-флешка теперь поднимается через однократную
  энумерацию (U1), короткие IN в control-передачах принимаются (U3), GBA-спам
  снят (G1/G2). Ждут стенда: фактический подъём флешки (SanDisk Cruzer Blade),
  клавиатура + флешка одновременно, CSW-residue/4Kn на флешке.
- **Звук** — возврат I2S/CPU2 отдельной большой дельтой.
- **FTP** — без TLS и без аутентификации (осознанно, доверенная LAN).
- **`.a8_bss`** — нет ASSERT на верхнюю границу в `linker.ld` (сейчас
  0x5F1D7310 < 0x5F800000, запас есть).
- **Сборка** — нет `-MMD`; `linkcheck` требует `arm-none-eabi-nm` в PATH.
