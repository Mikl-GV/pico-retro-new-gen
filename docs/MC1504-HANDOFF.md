```
Ты — эксперт по низкоуровневому программированию на Allwinner H3.
Проект: bare-metal мультисистемный эмулятор на Orange Pi Lite (H3, 4×Cortex-A7),
каталог /home/mikl/pico-retro-new-gen, ветка main.

СБОРКА: `bash -lc 'make clean && make -j16'` (login shell; нужен shim ~/bin/cygpath).
Тулчейн xPack arm-none-eabi-gcc 15.2.1. Бинарь build/h3_bare.bin -> корень h3_bare.bin.
Версию баннера поднимать при КАЖДОЙ сборке: h3_bare/src/main.c (r0.388 сейчас).
ВНИМАНИЕ: после правки ЛЮБОГО .h обязателен clean && make (зависимостей на .h нет).
Пуш/коммит — ТОЛЬКО по явному указанию пользователя.

СТАТУС: 19 систем + аркадные семейства FBNeo (CPS-1/CPS-2, NEOGEO/MVS, Toaplan,
Cave (68K), Sega System 16/18). План семейств — docs/ARCADES-PLAN.md.
Звук: настоящие ядра собраны (YM2612/2413/2151/..., AY8910=ports, YM2610=stub),
звук НЕ задействован; в логе при запуске любой системы печатается
`SND <sys> cores: ...` (манифест, helper snd_manifest в emu.c).

ЗАДАЧА СЛЕДУЮЩЕЙ СЕССИИ: **порт «Электроника МС 1504»** — первый советский
ноутбук (1990), процессор КР1834ВМ86 (i80C86, IBM PC/XT-совместимый, 4.77 МГц).
Эмуляция — 8086-машина XT-класса; основа с ВЕНДОРИТЬ ядро **Fake86**
(компактный 8086 PC/XT эмулятор, C). Уже в дереве:
  h3_bare/cores/ms1504/fake86_src/  (60 файлов, 652 КБ, скопировано из
  github.com/lgblgblgb/fake86-master; НЕ собрано, НЕ закоммичено)

ИМЕЮЩИЕСЯ ДАМПЫ МС1504 (в корне репозитория /MS1504/ и /MS1504/mc1504_docs/):
  - BIOS PK300 MC1504 27C512.bin    (65536 Б — ПЗУ, 8-бит)
  - mc1504BOOT.imz / mc1504SETUP.imz (архивы ZIP; внутри образы дискет 737280 Б = 720K)
  - MS1504_hdd_bios.256.bin         (32768 Б — HDD BIOS?)
  - mc1504docs.djvu                 (документация)

ПЛАН ПОРТА (по паттерну fuse/наших libretro-портов):
1. Отрезать SDL-зависимости fake86 (SDL в console.c/render.c/osd.c/main.c/input.c;
   экранируют — заменить на host-слой) и оставить ядро: cpu.c, bios.c, i8237.c,
   i8253.c, i8259.c, video.c (+ chip), ata.c/disk.c(образы), прочее без SDL.
2. Host h3_bare/cores/ms1504_ms1504.../ms1504_host.c:
   - загрузка BIOS (65К) и образов дискет в RAM/буферы из SD (`/roms/ms1504/`);
   - цикл execution (mainloop fake86 -> cpu_execute без SDL);
   - рендер: fake86 video.c (текст 80x25/CGA) -> наш EMU_FB/emu_scale (как emu.c);
   - ввод: USB-клавиатура -> PC-сканкоды (в fake86 есть походный перевод);
   - выход: ESC-удержание (emu_esc_hold), звук: пока off (манифест snd_manifest).
3. Makefile-секция (объекты ms1504_*), systems.h -> ms1504 READY
   (сейчас запись есть как PLANNED), меню/справка.
4. Сборка, отладка (это порт уровня fuse: несколько итераций; после первого
   кадра отгружать логи).

ПРИЕМЛЕМО: до первого запуска образа достаточно вывести загрузку BIOS (текст
POST/приглашателя) на экран. Настоящий «МС1504» кладбище — ПЗУ PK300 + образы.

ВАЖНО: исходники fake86 и дампы МС1504 пока НЕ в git (untracked; в репозитории
они в /MS1504/ и h3_bare/cores/ms1504/). Если решишь закоммитить заготовку —
предварительно уточни у пользователя (иначе НЕ коммитить).
```
