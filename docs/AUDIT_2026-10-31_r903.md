## 2. Полный список дефектов

### Конвейер I2S / SPSC

- **L1. (важн.) CPU2 без MMU читает ring напрямую — когерентность держится на
  отсутствии MMU у CPU2 + uncached у core0 (h3.c TEX=001).** Барьер «данные→dsb→индекс»
  корректен (i2s.c:184). Варианты: документировать инвариант / заложить DCCIMVAC на случай MMU.
- **L2. (важн.) `dsb` вместо `dmb` в продюсере.** Микро-потеря. Варианты: `dmb`/оставить `dsb`.
- **L3. (важн.) CPU2 NOP-backoff выжигает такты.** Варианты: `wfe/sev` / NOP-пауза.
- **L4. (крит.) I2S делители — фактически sun4i/эталон Bare_linux, не sun8i-H3
  (комментарий заявляет sun8i).** Частота 48 кГц достигнута эмпирически. Варианты: привести
  к чистым sun8i-H3 (стенд)/задокументировать эмпирику.
- **L6. (мелк.) `g_volume_pct` «читает CPU2» — ложь, читает только core0.**
- **L7. (важн.) `i2s_test_tone` дропает при полном ring.**

### GBA (gpSP)

- **G2. (важн.) 549 пар/кадр при 60 Гц = 32940/с ≠ 32768** — фаза компенсирует, не накапливается.
- **G8. (важн.) `init_sound` hardcode `gbc_sound_tick_step=256` (для 65536), а host
  ставит 32768 → envelope/sweep тактируются вдвое быстрее.** Реальная находка.
- **G9. `sound_freq_bits` не используется.**

### SNES

- **S1. (крит.) PAL OOB:** `SOUND_BUFFER_SIZE=2*44100/50=1764`, host зовёт `S9xMixSamples(sndbuf,1920)`
  на PAL → переполнение `MixBuffer` на 156 int32 (затирает `EchoBuffer`). Upstream использует 32040.
- **S2/S3. static аккумулятор/`SuperScopePosition`. Мелкие.**

### GPGX

- **M1. (важн.) `audio_init(48000,60.0)` хардкод 60 Гц ломает PAL pitch/темп.**
- **M2. (важн.) ghost-рендер EMU_FB вне viewport.**
- **M3. неидемпотентный byte-swap ROM.**

### Game Boy / Lynx / NGP / MSX / CPS1 / MS1504 / Portfolio / BK / FCEUmm

- **B1. (крит.) мёртвый `g_emu` при перезапуске (нет delete/NULL перед new).**
- **Lx1. static `last_l/rsample` не сбрасываются → поп при входе.**
- **Lx2. (крит.) мёртвый `g_lynx` при перезапуске.**
- **N1. ресемплер NGP сбрасывает фазу в 0 при неполном выводе (важн.).**
- **N2. `writeSaveGameFile` пустой — прогресс NGP не сохраняется (важн.).**
- **Mx1. `MSX_NUKEYKT` не выставлен → NukeYKT не звучит (важн.).**
- **Mx2. OOB `samples[idx+1]` в Sound.c:408 (латентный).**
- **C1. NEOGEO без звука (YM2610 заглушен) (важн.).**
- **C2. mc8123 защита не подключена к CPS1.**
- **C3. `nBurnSoundLen>2048` → OOB в cps_snd.**
- **P1. PC-спикер MS1504 ×45 ниже частоты (важн.).**
- **P2. Portfolio без звука вообще (важн.).**
- **Bk1. (крит.) BK двойной аудиопоток → переполнение ring.**
- **Bk2. BK бежит 1.2× (60 Гц throttle вместо 50) (важн.).**
- **F1. `soundq=0` (LQ) — HQ не запрошен (важн.).**

### Общее: static-фазы ресемплеров между играми (A7800/PCE/Fuse/NYA)
Важные, единый паттерн: сохранять остаток фазы; обнулять static в `*_init_game`.

## 5. Оценка точности

- Сходится: GBA, GB, Lynx, A5200, A2600(NTSC), Coleco, PCE(HuCard), Vectrex, Fuse(NTSC-шир).
- Приблизительно (дефект порта): SNES(PAL), GPGX(PAL), A7800(PAL), MSX(YM2413), CPS1(NEO),
  NGP(фаза), BK(1.2×), MS1504(спикер).
- Неверно/немо: Portfolio, NEO на CPS1-host.
- CPU-декодеры — свежие эталоны, нарушений не найдено.
