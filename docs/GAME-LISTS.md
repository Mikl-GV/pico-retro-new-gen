# Подборки игр для пустых папок `roms/`

Списки-цели для систем, под которые в `roms/` уже есть каталог, но нет содержимого
(и, как правило, нет ядра). До 40 позиций на систему, только то, что имеет смысл
портировать на H3. Состояние ядер — `h3_bare/cores/systems.h` и `docs/ROADMAP.md`.

Это перечни названий, а не ROM-файлы: коммерческие образы не распространяются,
комплектация — отдельная задача владельца.

Реальность порта на Orange Pi Lite (Cortex-A7, 512 МБ, без ОС):

| Метка | Значение |
|---|---|
| легко | Z80/6502-класс, ядро реально поднять |
| средне | 68K без тяжёлого видео |
| тяжело | 68K + кастомное видео / большой объём RAM |
| нет | x86-класс, 3D-железо или 386+ — за пределами платформы |

## Заполнять смысла нет

- **N64** — MIPS R4300i + 8 МБ RDRAM + 3D-видео; на H3 нереально при любом объёме работ.
  Канон, если понадобится для другого железa: Mario 64, Zelda OoT/MM, GoldenEye,
  MK64, F-Zero X, Banjo-Kazooie, Star Fox 64, Perfect Dark, Diddy Kong Racing,
  Paper Mario, Conker, Jet Force Gemini, Blast Corps, Wave Race, 1080, Smash Bros.
- **Model 1 (Sega)** — 3D-платы: Virtua Racing, Virtua Fighter, Star Wars Arcade,
  Wing War, Virtua Formula. Вне платформы.
- **Portfolio** — система builtin (`SYS_BUILTIN`), каталог пустой по делу.
- **TI-83** — калькулятор, игровой подборки не требуется.
- **atari8** — альтернативный каталог для `atari800` (`SYS_ALT`), отдельная система
  не нужна.
