# План разработки эмуляторов (послойный)

> Цель: расширить ретроконсоль pico-retro-new-gen (Orange Pi Lite, H3, bare-metal)
> новыми системами. Работаем **послойно** — каждый слой добавляет фундамент для следующего.
> Ограничения железа: Cortex-A7 @ 1.2 ГГц, 512 МБ ОЗУ, **без ОС, без JIT** (интерпретация).

---

## Слои (Roadmap)

### Слой 0 — Фундамент (уже готов)
- [x] Загрузка через U-Boot (`go 0x40000000`), 512 МБ карта памяти
- [x] UART0 (PA4/PA5), HDMI 1024×600, сенсор XPT2046
- [x] SD/FAT32 чтение ROM с карты
- [x] USB HID-клавиатура (OHCI)
- [x] Ядро 6502 (151 опкод, BCD, page penalties)
- [x] Atari 2600 / 5200 / 7800

### Слой 1 — Z80-ядро (открывает 5+ систем)
- [ ] Написать интерпретатор Z80 (~256 опкодов, +IX/IY, 16-бит)
- [ ] Память через callbacks (как cpu6502)
- [ ] Тест на известном коде

| Система | CPU | Характеристики | Сложность |

### Слой 3 — NES / Famicom (Dendy)
- [ ] PPU (2C02): паттерны, спрайты, палитры, скролл

- [ ] Поддержка .nes, в т.ч. Dendy-пираток

### Слой 6 — Русские ретро-компьютеры

### Нереализуемо в bare-metal (без JIT)

| SNES SuperFX | спецчип, слишком быстрый |
| Saturn / 3DO / PSP / DS | архитектура слишком сложна |

## Порядок работ

1. **Слой 1** — Z80-ядро (фундамент для 5 систем)
2. **Слой 2** — сначала простые: ZX Spectrum, ColecoVision → потом GB, MS
3. **Слой 3** — NES (Dendy) — самый желаемый
4. **Слой 4** — на пробу Mega Drive, потом PC Engine, SNES
5. **Слой 5** — русская ретро-классика

> Каждый слой: пишем ядро → тест на известном ROM → встраиваем в меню → показываем.
