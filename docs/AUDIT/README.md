# AUDIT — методика и реестр находок

Аудит кода порта (не эталона). Правки в код — **только после утверждения**
владельцем. Документы слоёв лежат рядом: `01_memory.md`, `02_hosts.md`,
`03_cores.md`, `04_video.md`; сводка и план выхода — `SUMMARY.md`.

## Критерии проверки (как проверяю)

Слой проверяется по одному, без перескоков; в документ попадает только то,
что подтверждено чтением кода/символами ELF/логом стенда. Для каждой находки
обязательны:

1. **ID** (`A-NN`), слой, серьёзность P1/P2/P3.
2. **Доказательство** — `file:line`, адрес из `nm`/`readelf`, строка лога.
3. **Влияние** — что именно ломается (падение, порча данных, тишина, темп).
4. **Проверка** — как убедиться, что это оно (лог, эксперимент, арифметика).
5. **Предложение** — минимальная правка, без реализации до утверждения.
6. Пометка **«требует проверки»**, если вывод не доказан, а гипотеза.

Правила: комментарии и документация могут лгать — истина только в коде и
ELF; «так в апстриме» не оправдание (в эталоне тоже есть ошибки — см.
раздел улучшений в `SUMMARY.md`); любая цифра (адрес, размер, частота)
пересчитывается, а не копируется.

## Порядок прохода

| Слой | Что проверяется | Документ |
|---|---|---|
| 1. Память | карта `docs/MEMORY.md` ↔ ELF, пулы, ZIP/ROM-буферы, перекрытия, аллокатор FBNeo | `01_memory.md` |
| 2. Хосты | `cores/*_host.*` ↔ документация/комментарии, границы кадров и звука | `02_hosts.md` |
| 3. Ядра/интеграция | известные дефекты (USB-доконфликт, звук, PAL/NTSC, мёртвый код, удаление, ROM-свап) | `03_cores.md` |
| 4. Видео | дрожание строк, видеофильтр как опция настроек (была раньше) | `04_video.md` |
| 5. Сводка | сведение, приоритеты, план выхода с проверками | `SUMMARY.md` |

## Известные проблемы владельца (вход в аудит)

1. Отваливается клавиатура при другой установке USB; конфликт с флешкой
   (пересечение памяти при большом списке файлов).
2. Плохой звук у части эмуляторов — «песок»; возможно, малы буферы.
3. Не работает автоопределение PAL/NTSC — игры идут быстрее; возможно,
   отсюда и звук.
4. Мёртвый код / остатки экспериментов.
5. Удаление файлов не работает — постоянные ретраи в логе.
6. Проблемы при загрузке ROM, свапе дисков, эмуляции FAT.
7. Помехи в звуке связаны с видео (возможно, конфликт памяти: кто-то пишет
   в звуковой буфер).
8. Нужен простой видеофильтр (дрожание строк в динамике; пропуск кадра
   не критичен) — как **опция в настройках** (была раньше).
9. NEOGEO падает — найти и починить.

## Реестр (обновляется по мере прохода)

| ID | Слой | Серьёзность | Кратко | Статус |
|---|---|---|---|---|
| A-01 | память | P1 | `g_frame` граничит с переменными NEOGEO — запись за кадр портит состояние | открыто |
| A-02 | память | P1 | `_BurnMalloc` при исчерпании пула возвращает NULL, `bprintf` — заглушка; пул 96 → 106 МБ | закрыто (r1641 + стенд: NEOGEO ОК) |
| A-03 | память | P2 | bump-пул не возвращает память до следующего `BurnDrvInit` | открыто |
| A-04 | память | P3 | ZIP-буферы впритык к `.gbc_bss`/`.coherent` (запас 0) | закрыто (r1642) |
| A-05 | звук/темп | P3 | `nBurnSoundLen` от FPS ≠ ровно 48 000 пар/с | открыто |
| A-06 | хосты | P3 | CPS: пуш > 2048 пар молча отбрасывается | закрыто (r1642) |
| A-07 | хосты | P3 | SNES hi-res 512 сжимается до 320 | открыто |
| A-08 | хосты | — | CPC в границах (HI 768×272 = буфер) | снято |
| A-09 | хосты | P3 | CPC: нет клампа `w/h` | закрыто (r1642) |
| A-10 | ядра | P2 | общий скретч каталога `g_scratch_dir` на 12 мест | требует данных |
| A-11 | звук | P2 | «песок» — ресемплер/DC, нужен список систем | требует данных |
| A-12 | темп | P2 | нет автодетекта PAL/NTSC | закрыто (r1645) |
| A-13 | код | P3 | мёртвый код: дубль `LOG_MEMORY_USAGE`, `cps_hw_scaler_active` | закрыто (r1642) |
| A-14 | FAT | P2 | ретраи удаления — из слоя записи/USB | закрыто (r1644) |
| A-15 | FAT | P2 | ROM/свап дисков/FAT — нужны сценарии | требует данных |
| A-16 | звук | P2 | помехи звука при видео — проверить `AUDIO-END` | требует данных |
| A-17 | UI | P3 | неудачное удаление молча закрывает браузер | закрыто (r1644) |
| A-18 | видео | P2 | нецелый вертикальный масштаб (600/224) → дрожание строк | снято (r1646): на лету падает |
