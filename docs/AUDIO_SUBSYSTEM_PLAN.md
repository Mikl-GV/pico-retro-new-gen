# План: аудио-подсистема pico-retro-new-gen (r735, 2026-10-06)

## Проблема (диагноз на текущий момент)

- I2S-TX-FIFO пишут **ДВА ядра**: Core2 (штатный цикл `audio_core.c`) и Core0
  (fallback в `emu_throttle`, emu.c:274-283) — гонка за единый аппаратный
  регистр → артефакты, щелчки, «доезд», ухудшение при перезаходах.
- Core2 **завис/умер** (по логу SLT: `act1/1 pau0/0 beat+0 L:2547720` одинаково
  во всех тестах — счётчики CPU2 не растут, heartbeat не тикает). Звук тащит
  Core0 fallback-ом — отсюда «песок/рваный/плавает».
- Причина смерти Core2 — выясняется (жду UART-лог: `ABT:/UND:`).

## Решение (принято): «навести порядок» (путь 2'), без строительства ОС

Надёжность дают три принципа, их и внедряем:

1. **Единственный владелец I2S-TX-FIFO** (или Core2, или железный DMA — не оба).
2. **Детект мёртвого ядра + гарантированное восстановление** (liveness + action).
3. **IPC без гонок** (SPSC-кольцо; fallback не должен ломать единственность
   потребителя).

## Шаги (порядок строго по приоритету)

### Шаг 1. Найти точку гибели Core2 (В ПРОЦЕССЕ)
- [x] Счётчики цикла CPU2 (loop/poll/flush/resume) в `.coherent` — audio_core.c.
- [x] Счётчики исключений: Data Abort → SRAM 0x24, Undefined → SRAM 0x28 —
      startup.S (`_dataabort`, `_undef`).
- [x] Печать `ABT:/UND:` + счётчиков CPU2 в SLT-тест — sound_layer_test.c.
- [ ] Получить UART-лог со стенда (тест GBA 1000) → определить ABT/UND.

### Шаг 2. Починить Core2
- [ ] По результату лога: либо чиним Core2 (исключение/спин), либо, если он
      нежизнеспособен — заменяем его роль железным DMA.

### Шаг 3. Убрать fallback из Core0 полностью
- [ ] Удалить `i2s_flush_max(24)` из `emu_throttle` (emu.c:274-283).
- [ ] Core0 ТОЛЬКО льёт в кольцо (`i2s_push_sample`) — единственный писатель
      FIFO остаётся Core2 (или DMA).
- [ ] Проверить: тон-тесты, клики меню, все эмуляторы без артефактов.

### Шаг 4. Аудио-модуль с чистым API
- [ ] `audio_init() / audio_push() / audio_flush()` — эмуляторы не знают,
      поллинг там или DMA.
- [ ] Обернуть существующий i2s.c/audio_core.c в этот API (без переписывания
      ядер).

### Шаг 5. Железный DMA (sunxi-DMA → I2S TX)
- [ ] Инициализация sunxi-DMA, дескрипторы, IRQ.
- [ ] Направление IRQ DMA на нужное ядро (GIC -> Core2).
- [ ] Кольцо → DMA-очередь → TX FIFO; CPU2 управляет дескрипторами.
- [ ] Снять с Core0 и Core2 ручное копирование пар.

## Критерии готовности (когда считаем звук сделанным)

- [ ] Чистый тон 440/1000/3000 слышен в тесте без «песка/плавания», `dropped≈0`.
- [ ] В эмуляторах нет щелчков/доезда/ухудшения при перезаходах.
- [ ] Единственный писатель I2S-FIFO (проверяется по коду: fallback удалён).
- [ ] Liveness CPU2 работает: при зависании Core2 — детект + восстановление,
      а не тихая подмена на Core0.

## Решение по архитектуре (зафиксировано)

- **НЕ строим** полноценную мини-ОС сейчас: для ретро-консоли с фиксированным
  набором систем это больше движущихся частей = больше отказов.
- **Наводим порядок** (путь 2'): чистые абстракции поверх работающего кода.
- Если расширение потребует — флаговый автомат перерастёт в планировщик
  естественно, без переписывания низов.
