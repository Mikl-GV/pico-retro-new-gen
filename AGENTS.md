# AGENTS.md — правила проекта pico-retro-new-gen

## Сборка

- ЕДИНЫЙ источник истины по сборке — `Makefile` (состав файлов, флаги,
  rename-скрипты, линковка). Все изменения состава прошивки — только там.
- `build.sh` и `build.ps1` — тонкие обёртки над `make` (цели: без аргумента,
  clean, sd, fel). НЕ добавлять в них прямые рецепты/списки файлов.
- После правки любого `.h` (изменения макросов/констант) — `make clean && make`:
  зависимости отслеживаются (`-MMD -MP`, `build/deps.mk`, r1155), но чистая
  сборка — правило владельца и страховка от рассинхрона макросов/ABI структур.
- Версия прошивки: текущая — **r1260** (нумерация с r500). Версия присваивается
  **на КАЖДОЕ изменение/компиляцию** (см. «Правила владельца»). Обновлять
  `g_fw_version` и строку `build:` в `h3_bare/src/main.c` И точку сохранения
  в `docs/HANDOVER.md` / реестр в `docs/` — всё должно быть синхронно.
- **Карта памяти и правила размещения — `docs/MEMORY.md`** (адреса, владельцы
  зон, перекрытия, LPAE/MAIR, свободные зоны, чек-лист для новых ядер).

## Git

- Коммит и пуш — ТОЛЬКО по явной просьбе пользователя («пуш», «коммить»).
- В GitHub репозиторий не должны попадать: PDF, .col, host/, emulator-refs/,
  roms/ (в .gitignore).

## Архитектурные решения (не менять без согласования)

- HDMI-меню/навигация — главный путь (клавиатура/джойстик); TFT — только
  дополнение (тап иконок Settings/About). HDMI-экраны не заменять TFT-версиями.
- Читы ОТКЛЮЧЕНЫ (r500) до послойной доработки; `cheats_reset()` в
  `emu_prepare()` гарантирует пустой список. Не включать частично.
- Вентилятор/ths_fan УДАЛЁН (r500) — не возвращать без решения владельца.
- Стенд-зависимые файлы (sega_pad.c — шапка «НЕ ЛАЗИТЬ БЕЗ СТЕНДА») не
  править без живого железа.
- **MMU: карта DRAM от U-Boot — НЕ перестраивать.** `TTBCR`/`TTBR0`/`TTBR1`
  не менять никогда (r1195 → hang после `remap: loaded`; r1197 → hang после
  `123`). U-Boot работает в **LPAE**: `startup.S` копирует L0 в `0x4A40C000` и
  L1 в `0x4A410000+` (иначе стек `0x60000000` затирает таблицы — корень r1202).
  `mmu_mark_uncached()` — намеренный no-op (r1206): `.coherent` остаётся
  write-back, NC-маппинг ломает OHCI; `mmu_map_dram_cacheable()` удалена.
  Новые дескрипторы — только 64-битные long. Подробно — `docs/MEMORY.md`,
  `docs/PITFALLS.md`.
- **Сборка — прямым `make -j20`** (PATH: `C:\msys64\usr\bin` +
  `C:\ARM\gcc-arm-none-eabi-15.2.1\bin`), без bash-обёрток и без `-j8`.
- **Файлы с кириллицей править только инструментом edit/write**:
  PowerShell `Set-Content`/`-replace` портит UTF-8 (README ловили r867/r1198).

## Правила владельца (заданы 2026-10-01, обязательны)

1. **Язык.** Отвечай И рассуждай на русском.
2. **Документация — каждое изменение.** Любая правка кода сопровождается записью
   в документации проекта (точка сохранения: `docs/HANDOVER.md`).
3. **Версия — на каждую компиляцию/изменение.** При каждом изменении присваивать
   новую версию: инкремент `g_fw_version` и строки `build:` в
   `h3_bare/src/main.c` + синхронизировать документы. Старые «r537/r521/r502»
   одновременно в разных файлах недопустимы.
4. **BIOS/ROM — ВШИТЫ в прошивку.** Спец-BIOS (например GBA) берётся из образа
   прошивки (`.incbin` через `bios_data.S`), НЕ подгружается с SD. Загрузка с SD
   для вшитого BIOS запрещена.
5. **Звук — синтез СОХРАНЯТЬ, вывод возвращён (r895+).** Синтез в ядрах и
   host-слоях обязателен при портировании новых систем (вызовы `i2s_*`
   остаются). С r895 звуковой вывод I2S0/CPU2 проектируется заново по железу
   H3 (даташит + sun4i-i2s.c); `i2s.c` — рабочий слой (ring .coherent → CPU2
   доливает TX FIFO), `cpu2_audio_entry` — вечный цикл долива (не `wfi`).
   Решение владельца r777 (полное снятие вывода) отменено отдельными
   дельтами r895..r902; не откатывать без согласования.
6. **GitHub — не помойка.** В репозитории только актуальное; сборка обязана
   проходить на ДРУГИХ машинах (проверка из свежего клона:
   `git clone . /tmp/x && cd /tmp/x && make clean && make`). Никакого мусора,
   бинарных хвостов и «временных» трейсов в закоммиченном коде.
