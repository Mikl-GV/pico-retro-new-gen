# AGENTS.md — правила проекта pico-retro-new-gen

## Сборка

- ЕДИНЫЙ источник истины по сборке — `Makefile` (состав файлов, флаги,
  rename-скрипты, линковка). Все изменения состава прошивки — только там.
- `build.sh` и `build.ps1` — тонкие обёртки над `make` (цели: без аргумента,
  clean, sd, fel). НЕ добавлять в них прямые рецепты/списки файлов.
- После правки любого `.h` (изменения макросов/констант) — `make clean && make`,
  иначе объекты останутся со старыми константами (нет отслеживания зависимостей).
- Версия прошивки: r500. Обновлять `g_fw_version` и строку `build:` в `h3_bare/src/main.c`.

## Git

- Коммит и пуш — ТОЛЬКО по явной просьбе пользователя («пуш», «коммить»).
- В GitHub репозиторий не должны попадать: PDF, .col, host/, emulator-refs/,
  roms/ (в .gitignore).

## Архитектурные решения (не менять без согласования)

- HDMI-меню/навигация — главный путь (клавиатура/джойстик); TFT — только
  дополнение (тап иконок Settings/About). HDMI-экраны не заменять TFT-версиями.
- Читы ОТКЛЮЧЕНЫ (r500) до послойной доработки; `cheats_reset()` в
  `emu_prepare()` гарантирует пустой список. Не включать частично.
- Вентилятор/ths_fan УДАЛЁН (r500) — не возвращать без решения владельца.
- Стенд-зависимые файлы (sega_pad.c — шапка «НЕ ЛАЗИТЬ БЕЗ СТЕНДА») не
  править без живого железа.
- Реестр найденного и статусы: `docs/AUDIT-2026-09-30.md`.
