# MultiTool TwinCommander

Двухпанельный файловый менеджер (как Total Commander) для обмена файлами
между ПК и ретро-консолью (pico-retro-new-gen, RTL8189FTV WiFi, FTP-сервер на H3).

## Запуск

- **Готовый exe:** `dist/twin_commander.exe` (собран PyInstaller, Python 3.14, tkinter вшит).
- **Из исходника:** `python twin_commander.py`.

## Интерфейс

```
┌──────────────────────────┬──────────────────────────┐
│ [Левая: компьютер]       │ [Правая: SD/USB консоли]  │
│  /roms/dir/              │  /roms  (10.233.48.44)    │
│  папка1/                 │  A2600/                   │
│  папка2/                 │  NES/                     │
│  game.rom   512 КБ       │  game.rom      1.2 МБ     │
└──────────────────────────┴──────────────────────────┘
  [← Копировать] [Копировать →] [↑ Вверх] [Новая папка] [Удалить] [Обновить]
```

- **Левая панель** — файлы на компьютере.
- **Правая панель** — файлы на SD/USB консоли (FTP, начинается с `/roms`).
- Активная панель подсвечена.

## Управление

| Действие | Как |
|---|---|
| Сменить активную панель | `Tab` или клик |
| Войти в папку | `Enter` / двойной клик |
| Вверх | `BackSpace` или кнопка «↑ Вверх» |
| Копировать в другую панель | `F5` или кнопки «← Копировать» / «Копировать →» |
| Удалить | `F8` / `Del` или кнопка «Удалить» |
| Новая папка | `F7` или кнопка |
| Обновить | `F2` или кнопка |
| **Автопоиск консоли** | кнопка «Найти консоль» — сканирует подсеть, ищет открытый порт 21 |

## Использование

1. Включить WiFi на консоли (меню «Настройки → WiFi Transfer»), дождаться IP
   (в UART-логе `DHCP OK ip=...`).
2. Запустить `twin_commander.exe`.
3. Нажать **«Найти консоль»** — программа сама найдёт консоль в подсети и
   подключится. Либо вписать IP вручную и нажать «Подключить».
4. Выделить файл на ПК, нажать **«Копировать →»** — уйдёт на консоль в текущую
   папку правой панели. И наоборот: выделить на консоли, «← Копировать» — на ПК.

## Сборка exe

```bat
pyinstaller --onefile --windowed --name twin_commander twin_commander.py
```

## Структура

- `twin_commander.py` — исходник (tkinter GUI + ftplib, без зависимостей)
- `ftp_client.py` — старая однопанельная версия (не обязательна)
- `dist/twin_commander.exe` — готовый exe
- `build/`, `*.spec`, `__pycache__` — артефакты сборки (не коммитить)
